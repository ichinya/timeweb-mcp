# Отдельные будущие задачи новых сервисов

Источник — группы официального OpenAPI, сверенного в issue #27. Это локальный backlog,
не опубликованные GitHub issues и не обещание существующей поддержки MCP.
Каждая задача требует отдельного исследования request/response, прав доступа, ошибок,
стоимости операций, annotations и fixtures до подключения инструментов.

- [ ] CDN: изучить управление сервисами и кешем; отдельно согласовать операции изменения.
- [ ] AI Gateway: изучить управление ключами и статистику без раскрытия секретов.
- [ ] AI Gateway API: отдельно исследовать вызовы моделей, потоковые ответы и учёт расходов.
- [ ] MCP: изучить управление подключениями и ресурсами, не смешивая модели MCP и compute.
- [ ] Навыки AI агентов: исследовать управление навыками и совместимость с агентами.
- [ ] Интеграции AI агентов: исследовать подключения, OAuth и жизненный цикл авторизации.
- [ ] AI Модели: исследовать каталог, параметры и доступность моделей.
- [ ] AI-решения: исследовать сценарии создания и управления, включая платные действия.
