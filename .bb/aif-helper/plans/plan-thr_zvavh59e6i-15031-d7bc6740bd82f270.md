# Issue #29 — подтвердить устранение advisories и обновить Axios

## Цель

Зафиксировать актуальное состояние production-зависимостей и применимость исторических advisories. Выполнить ограниченное обновление Axios с 1.21.0 до 1.21.1, сохранив совместимость HTTP-клиента и MCP.

Исследование показало нулевой production audit на текущем lockfile. Обновление Axios повышает минимальную версию follow-redirects; не представлять его как устранение обнаруженной уязвимости текущего дерева, где уже установлен follow-redirects 1.16.3.

## Ограничения

- Перед изменениями перечитать применимые AGENTS.md, проверить HEAD, git status и diff.
- Сохранить незакоммиченные изменения #28: scripts в package.json, README, новый verify.yml и выбранный для #28 план.
- Scope #29: версия Axios в package.json, связанные записи package-lock.json, документация аудита и evidence в supporting artifacts текущего чата.
- Не обновлять остальные прямые зависимости и devDependencies, не повышать версию самого пакета.
- Не выполнять новую миграцию MCP SDK или Zod: её необходимость текущим исследованием не подтверждена.
- Не использовать npm audit fix, --force или overrides. Не выполнять массовое npm update.
- Не менять API-клиенты, workflows, спецификацию или существующие тесты без воспроизведённой регрессии от обновления.
- Не читать production .env, не использовать реальные Timeweb-токены и не выполнять облачные операции.
- Не выполнять коммит, push, публикацию, изменение GitHub settings или закрытие issue.
- Нулевой audit означает отсутствие известных сообщений в проверенном источнике на указанную дату, а не доказанную безопасность приложения.
